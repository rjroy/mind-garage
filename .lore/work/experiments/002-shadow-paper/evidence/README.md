# Reproducing the shadow-paper pilot

Generated evidence is not committed. Local discussion captures, recordings, logs and manifests belong under `.lore/local/experiments/002-shadow-paper/`, if retained. The [experiment record](../record.md) documents results and limitations without requiring those files.

The existing local `evidence/` package preserves the C01/C02-corrected snapshot, **before C03**. It is historical discussion material, not the final accepted source. See its local provenance for that capture's exact source identity and commands.

## Run the current checks

From the repository root:

```sh
godot --headless --path games/borrowed-turns --script res://tests/shadow_rendering_run.gd
godot --headless --path games/borrowed-turns --script res://tests/shadow_presentation_run.gd
godot --headless --path games/borrowed-turns --script res://tests/run.gd
godot --headless --path games/borrowed-turns --script res://ui/smoke.gd
python3 games/borrowed-turns/tools/rendered_smoke_gate.py \
  --capture-dir /tmp/opencode/borrowed-turns-fresh-smoke --timeout 120
```

The gate requires a new, nonexistent capture directory and checks completion, not merely process exit status. Tests do not establish visual appeal or enjoyment.

## Generate discussion captures

With a graphical renderer and a new output path:

```sh
godot --path games/borrowed-turns \
  --script res://tools/capture_shadow_pilot.gd \
  -- --out-dir=/tmp/opencode/borrowed-turns-fresh-capture
```

The tool produces labeled stills, frame sequences and a manifest. Encode clips from the generated frames with FFmpeg if needed; read the actual frame counts from that run rather than assuming historical counts. Retain outputs only in temporary storage or gitignored `.lore/local/`. Record the source commit, command, result and any meaningful interpretation in documentation.

The tested engine was Godot `4.7.2.stable.arch_linux.ed1daf0bf`. Captures use SubViewports and injected controls, not physical input, compositor-native resizing or HiDPI acceptance. Timing and graphics drivers can change generated bytes. This limited pilot does not fairly represent finished shadow-paper aesthetic appeal; FY3 remains open for Ronald's reaction.
