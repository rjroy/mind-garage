# Borrowed Turns: design history

[Play Borrowed Turns](../../../../games/borrowed-turns/README.md) · [Mind Garage design library](../../../README.md)

The prototype asks what happens when the player can borrow an opponent's announced attack. For the outcome, see [Ronald's verdict in the project overview](../../../../README.md). For how the design changed, follow the experiment records:

| Experiment | Focus |
| --- | --- |
| [001: Hook discovery](experiments/001-hook-discovery/record.md) | Original proposal, mechanic variants, and revisions |
| [002: Shadow paper](experiments/002-shadow-paper/record.md) | Making the fight legible as a theatrical performance |
| [003: Active opponents](experiments/003-active-opponents/record.md) | What capturing and reusing an ability feels like in a fight |
| [004: Switcher](experiments/004-switcher/record.md) | A new opponent that exchanges positions with its target |
| [005: Opponent library](experiments/005-opponent-library/record.md) | Independent opponent trials and their mechanical checks |

For the design behind the trials, see the [visual direction](design/art/visual-systems-direction.md), [Curtain Call narrative brief](design/narrative/curtain-call-narrative-brief.md), and [opponent shortlist](design/borrowed-turns-opponents.md). The [game-specific research](research/) and [visual exploration retrospective](retro/borrowed-turns-visual-exploration-retrospective.md) give context for those choices.
