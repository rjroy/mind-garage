## Where a new document goes

If it applies before choosing a game, file it under `work/shared/`. If it describes a particular game's design, playtest, or result, file it under `work/games/<game-id>/`. Use the same ID as `games/<game-id>/`, add the game to this index, and create subfolders only as needed. Each experiment gets its own `experiments/<experiment-id>/record.md` within its game.

Link to shared originals. Copies captured under an experiment's `inputs/` document what was available at the time; don't update them to match later edits. Keep generated output in ignored `.lore/local/`, not alongside the tracked records.
