# Last Light on the Rink

The neighborhood rink is closing. Skate one last number with the lantern troupe.

```sh
godot --path games/last-light-on-the-rink
```

Run from the repository root with Godot 4.7.2. No plug-ins, downloaded art, saves, or network connection are required.

| Key | On the ice |
| --- | --- |
| WASD or arrow keys | Push toward a direction. Let go to coast. |
| Hold Space, then release | Dig an edge and leave a groove. |
| E | Invite a partner onto the last finished groove. |
| Esc / M | Pause / mute. |
| R | Start a fresh evening. |

Cross a cut at a shallow angle to catch it. Steer across it to peel out. The lines you leave in rehearsal are the lines the troupe can skate in the closing show. There's no score or required pattern.
